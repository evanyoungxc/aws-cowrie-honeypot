# Cowrie Honeypot Dashboard

I built a live web dashboard for my AWS Cowrie honeypot to make captured activity easier to monitor and analyze.

**Live Dashboard:** http://54.210.18.142/index.html

The dashboard runs on the same AWS EC2 instance as Cowrie and is served using Nginx.

Cowrie generates JSON event logs containing information about SSH connections, authentication attempts, commands, and file transfers. A Python script processes these logs and generates a sanitized `data.json` file for the dashboard.

A systemd timer runs the parser every minute, while the frontend checks for new data every 30 seconds.

## Current Features

- Total SSH connections
- Unique source IPs
- Successful and failed authentication attempts
- Commands captured
- File transfer events
- Daily connection activity
- Daily successful login activity
- Recent connections
- Top source IPs
- Top usernames
- Top commands
- Recent commands
- HASSH fingerprint tracking

## Data Flow

Cowrie logs → Python parser → sanitized JSON → Nginx → browser dashboard

The activity chart compares total SSH connections with successful Cowrie authentications over time, making spikes in scanning and credential activity easier to identify.

## Security

The public dashboard only receives sanitized telemetry generated by the Python parser.

The following are not exposed through the web server:

- Raw Cowrie logs
- Captured passwords
- Malware or transferred payloads
- SSH private keys
- Administrative SSH access

## Updating

Dashboard data is regenerated automatically using a systemd timer. The browser requests updated data every 30 seconds.
